# Канал обновлений Tetra Music Library

Здесь лежат только подписанные релизы: установщик, его minisign-подпись
(`.sig`) и `latest.json` для автообновления.

Исходники приложения — в приватном репозитории `tetra-music-library`.

Не скачивайте файлы отсюда вручную без необходимости: приложение обновляется
само через Настройки → Обновления.
